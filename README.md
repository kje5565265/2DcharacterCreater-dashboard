# 2D 캐릭터 리소스 자동생산 파이프라인 — 대시보드

**바로 보기 → https://kje5565265.github.io/2DcharacterCreater-dashboard/**

게임용 2D 몬스터를 **말 한 줄과 AI 시안 한 장**에서 시작해 게임 엔진(Unity)에 넣을 리소스까지 자동으로 만드는 파이프라인의 작업 화면입니다.
이 페이지는 실제 개발 도구의 **읽기 전용 사본**입니다 — 만든 결과를 단계별로 볼 수 있고, 새로 만드는 기능은 꺼 두었습니다.

## 단계

| 단계 | 하는 일 | 맡는 쪽 |
|---|---|---|
| 1. 시안 | 주문 문장을 해석해 서로 다른 시안을 여러 장 그리고, 사람이 하나를 고른다 | AI(Codex) + 사람 |
| 2. 4방향 몸 | 정면 시안에서 뒷모습 · 옆모습을 만든다 | 코드 |
| 3. 표정 | 동작마다 갈아 끼울 표정을 만든다 | AI + 코드 |
| 4. 리그 조립 | 방향별 뼈대(리그)와 동작 데이터를 붙인다 | 코드 |
| 5. 클립 렌더 | 리그를 관절 기준으로 움직여 프레임을 찍는다 | 코드 |
| 6. 검수 GIF | 같은 동작을 방향별로 나란히 놓고 사람이 OK 또는 피드백 | 사람 |
| 7. 엔진 에셋 | 스프라이트 시트 + 스펙 → Unity | 코드 |

사람이 멈추는 곳은 **시안 확정 · 애니메이션 검수 · 엔진 투입** 셋뿐이고, 그 사이는 자동으로 이어집니다.

## 들어 있는 것

- 슬라임 원본과 속성 베리에이션 6종(대지 · 불꽃 · 얼음 · 번개 · 물 · 바람) — 4방향 × 7동작 25클립, 엔진 시트까지
- 반벗겨진 지우개 · 스마트폰 — 슬라임 틀을 물려받지 않고 모티프와 무관한 일반 경로로 만든 몬스터
